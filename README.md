# 7 Card Stud Mini

CPU対戦型の7カードスタッドポーカー Web アプリケーションです。

## セットアップ

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで表示されたURL（通常 http://localhost:5173）にアクセスしてください。

### その他のコマンド

| コマンド | 説明 |
|---|---|
| `npm run build` | 本番用ビルド |
| `npm test` | テスト実行 |
| `npm run test:watch` | テスト（ウォッチモード） |
| `npm run typecheck` | 型チェック |

## 遊び方

### ゲームの流れ

1. 「新規ゲーム」ボタンを押してゲームを開始します
2. プレイヤーとCPUにそれぞれ3枚のカードが配られます（サードストリート）
3. 各ストリートでアクション（bet / check / call / fold）を選択します
4. ストリートごとにカードが1枚ずつ追加され、セブンスストリートまで進行します
5. セブンスストリート終了後、ショーダウンで手役を比較し勝敗が決まります
6. 「次のラウンド」ボタンで続けてプレイできます

### アクション

| アクション | 説明 |
|---|---|
| **bet** | チップを賭ける（相手のベットがない場合） |
| **check** | パスする（相手のベットがない場合） |
| **call** | 相手のベットに合わせる |
| **fold** | 降りる（ポットを相手に渡す） |

### ストリート構成

| ストリート | カード枚数 | 配り方 |
|---|---|---|
| サード (third) | 3枚 | 裏2枚 + 表1枚 |
| フォース (fourth) | 4枚 | 表向きで追加 |
| フィフス (fifth) | 5枚 | 表向きで追加 |
| シックス (sixth) | 6枚 | 表向きで追加 |
| セブンス (seventh) | 7枚 | 裏向きで追加 |

### ゲーム設定

- 初期チップ: 1,000
- アンティ: 10
- ベットサイズ: 20（固定）

### 統計

画面下部に勝敗統計（ゲーム数・勝利・敗北・勝率）が表示されます。「新規ゲーム」で統計はリセットされます。

### 注意事項

- ブラウザをリロードするとゲーム状態がリセットされます
